# Problem Report

This is a list of the main areas on the Information and Problems pages. This focuses on the "Release Notes" page but "About" and "Report a Problem" are selectable from the list at the bottom of the page. 

## Report

Tap this button to report an issue direct to the bug management database. The report will contain some information about what you were doing, the state of the application at the time, and whatever text you choose to provide. Please describe your issue in that text.

## Mail

Tap this button to report an issue in email to DivisiBill support. You can control what information is sent by editing the mail before sending. Please describe your issue in that text.

## Issue

This is where you describe the issue you are reporting.

## Clear

This button clears the issue text (it can be restored by tapping the UnClear button). It is only enabled if there is any text in the issue area.

## UnClear

This button appends whatever issue text was last cleared. It is enabled only if some text has previously been cleared.

## Selectable Options

As well as this "Release Notes" page, you can select the "About" or the "Report a Problem" pages.

- About

    This contains information about the running version of DivisiBill.

- Release Notes

    A list of the latest changes in DivisiBill.
