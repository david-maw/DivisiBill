# Optional Licenses

This is a list of areas on the Optional Licenses page as seen from top to bottom. For more information about licensing see  [licensing help](licensing.html).

## Subscribe

This allows you to purchase a Professional Edition subscription to enable cloud operations in DivisiBill. Once you purchased a subscription, this button is replaced by the "Modify" button which allows you to turn off automatic subscription renewal.

## Modify

If you have already purchased the Professional Edition subscription, this button replaces the subscribe button and opens up a web site to permit you to view, modify or cancel your subscription.

## Purchase

This allows you to purchase a perpetual Professional Edition license to enable cloud operations in DivisiBill; it provides exactly the same features as a subscription but instead of an annual fee you make a one-time payment. Once you purchased a license, this button is replaced by the "Delete" button.

## Delete

This allows you to delete your perpetual Professional Edition license - there is no obvious reason why you might want to do this but the capability exists.

## Status

This shows you your purchase order number if you have purchased OCR scans (there's a similar display for professional licenses or subscriptions).

## Scans

All versions of DivisiBill allow you to purchase "scans" to extract information from a picture of a printed bill using cloud-based OCR scanning from the [Image](imagepage.html) page. Each OCR operation consumes one scan; when the number of scans remaining reaches zero, you must buy more before another OCR operation will be allowed. (For more details see [this](licensing.html) page.) This area will show you how many scans you have remaining. If you only have a few remaining, it will enable the "Purchase Scans" button to order additional scans.

## Purchase Scans

This button is only enabled when you have a small number of scans remaining, tap it to purchase additional scans.

## Cancel

This button allows you to return to the Settings page without changing anything.
